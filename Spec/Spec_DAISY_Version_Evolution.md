## 2026-08-10 — DAISY v1.6.3（本地 UI 整理检查点）

- 调整：顶部功能入口改为「扫描建库、快照对比、数据核验、数据解析、硬盘登记、环境检测」，
  高频档案工作流在前，设备与环境入口在后；页面标题、进度和报告仍保留完整名称。
- 统一：扫描建库与数据核验的「档案根目录」均使用可编辑目录列表，继续接受路径或
  「根目录名=路径」，不改变 `--root` 参数。
- 统一：硬盘选择的每个设备槽位使用相同边框、内边距与等高布局；可用性只通过状态文字、
  颜色和选择状态表达。
- 调整：「解析数据库」与「检测硬盘」改用同一浅绿色主操作样式。
- 调整：菜单栏按「文件／功能／视图／设置／高级／帮助」重排；功能分为档案、设备、环境，
  工具路径移入设置，运行选项保留在高级。工具状态不再把完整路径塞入菜单项，菜单文字与
  正文使用同一字号。
- 对齐：顶部六个功能按钮与环境页六个检测／安装列共享横向起点、按钮宽度和间距；普通与
  紧凑布局均按实际 Tk 坐标验证。
- 文案：扫描页哈希按钮使用「不采集／SHA-256」两态，继续映射既有 `none`／`full` 参数。
- 交互：数据库路径选择和输入框失焦不再触发读取，只有「解析数据库」按钮会执行只读识别；
  识别结果显示快照／Diff 来源版本。数据模块改为绿色已选、黄色可选、灰色不可用的按钮。
- 布局：快照 15 个模块采用不超过六字的明确界面名和固定按钮尺寸；调整窗口时只重新换行，
  不拉伸按钮。模块区四边留白一致并靠左排列，全选／取消选择与浏览按钮同尺寸。点击
  「解析数据库」只原位更新识别摘要和模块池，不再切换面板、重建表单或重置滚动位置。
  稳定模块 ID 和导出标题不变。
- 操作：底部从右向左固定为开始／停止、暂停／继续、打开结果目录；运行时同一开始按钮原位
  变为橙色停止，暂停后才显示保存并退出。暂停和保存使用统一的浅绿色，结果目录使用米黄色。
- 统一：所有任务表单离散选择改用按钮，续传重试范围使用三按钮；文件选择小按钮统一为
  「添加／选择／浏览」。数据库解析的摘要／全部／自定义预设原位刷新模块池，切换时不再
  重建整页或覆盖输出格式选择。
- 调整：顶部功能栏入口统一为「重置软件」，并移除「设置」菜单内重复的恢复入口；重置同时
  恢复界面默认值并清理会话数据和可重建缓存，不触及任务产物。底部开始／停止、暂停／继续、
  保存与打开结果目录使用同一行和固定顺序；三个常驻按钮与日志工具等宽、与表单模式按钮等高。
  任务产出结果后默认不再弹出目录询问，让与顶部六入口同色的目录按钮以绿色闪烁两次；设置中
  可单独启用结果目录提示。
- 调整：运行环境检测的状态与安装按钮改为紧凑固定宽度，保持上下六列对齐但不填满整行。
- 配置：GUI 用户配置格式更新为版本 3，新增默认关闭的
  `result_directory_prompt_enabled`；旧配置缺失该键时安全回退。
- 兼容：DBS schema 3／统一扫描 schema 4、STG archive schema 3、Diff、Reader、扫描参数与
  v1.4.1/schema 3 FULL 只读兼容边界均不变。
- 状态：本条记录尚不是远端正式发布；不得据此声称已有 `v1.6.3` tag。
- 文档：[v1.6.3 UI 整理计划](Spec_DAISY_V1_6_3_Release_Plan.md)和
  [v1.6.3 测试记录](Spec_DAISY_V1_6_3_Test_Record.md)。

## 2026-08-08～09 — DAISY v1.6.1（初步 UI 与扫描选择优化）

- 定位：本版用于收敛 UI 与交互，虽已完成仓库自动化验收，但仍可能存在真实工具、特殊
  文件、超大档案和不同 Windows 显示环境下的问题；它不是稳定发布，不建立标签。

- 改进：顶部 6 个功能入口固定为一排、统一为 6 个字；最终改用与表单模式按钮相同的
  原生 Tk 平直外形，按相同比例放大并整组靠左。浅米黄色选中态不改变按钮宽高，窗口变宽
  时也不再把入口拉成长条。
- 改进：扫描页先显示「完整扫描」和「快速扫描」两个按钮，选择后才展开对应设置；
  不再把未选择误作默认完整扫描。
- 新增：统一完整扫描只显示 ExifTool 与 ffprobe 两个按钮，各自在
  「全量 → 基础 → 关闭」之间循环；混合范围直接控制既有工具原始输出，不增加数据库
  表或列。旧配置仍按全局范围兼容解释。
- 改进：统一 schema 4 新快照文件名只保留 `Full`/`Quick` 模式，不再用功能标记区分；
  实际能力以冻结配置和运行清单为准，schema 3 旧名称继续兼容。
- 改进：扫描页只负责建立数据库，不显示格式校验或 RAW 深度校验；档案数据核验使用内置格式校验、
  ExifTool、ffprobe、7-Zip、rawpy/LibRaw 五个完整名称同排按钮，可用项默认全部开启且不提供
  抽样滑块。
- 改进：取消二元选项的按钮／下拉样式切换，严格二元字段统一使用黄／绿按钮；旧偏好键
  自动忽略。档案数据解析的输出格式改用可独立开关的多选按钮；续传重试范围继续使用下拉菜单，
  超时处置使用高级菜单单选项。
- 修复：保留的下拉选择重复选择当前选项后不再因系统选中态变为白字；按钮状态文字变化造成
  尺寸跳动；空目录控件占用不必要纵向空间。
- 新增：运行环境检测使用六个完整名称同排状态按钮显示外部工具与 rawpy/LibRaw 能力；等待检测为
  灰色，点击任一状态按钮均可开始或重新检测。安装区五个操作的第一行显示工具名、第二行
  显示「安装或更新」；PowerShell 第二行显示「系统提供」并禁用，六列逐列对齐且宽高一致。
  rawpy 经用户确认后仅使用当前 Python 的固定 pip 白名单安装，随后通过隔离能力探测层
  复检；Tk 主进程不导入 rawpy。
- 改进：普通按钮组使用统一尺寸和 12 px 间距；扫描与核验的「添加目录」均置于路径内容
  上方；滚动判定容忍 2 px Tk 几何取整，避免无实际溢出时出现空滚动。
- 改进：标准正文基准由 11 号降为 10 号；较大／特大分别增加 1 号和 2 号，完整工具名称
  通过两行按钮保持在窄窗口和高缩放下可见，并显式逐行居中。
- 改进：全部 Tk/ttk 按钮和管理员模式按钮统一使用正文 10 号常规字重；按钮层级继续
  由颜色、尺寸和位置表达，不再使用额外粗体。
- 修复：扫描设置切换改为离屏构建后原子替换；不影响条件字段的建库方式不再整页重建，
  消除切换时先清空后出现的闪动。
- 改进：扫描分区「扫描功能」改为「采集内容」，文件身份项改名 `NTFS-ID` 并明确说明实际
  采集卷序列号与文件索引；对比页用左右两栏编辑基准／对比根目录名，指纹降级移至
  「高级→对比行为」，CLI 参数和默认值不变。
- 改进：任务队列真正结束后重新展开设置；小窗任务结束先返回完整界面，安装自动复检
  中途不闪动，硬盘检测仍返回专用硬盘选择布局。
- 改进：点击软件安装项后先在后台以固定白名单命令查询软件源最新版本，成功解析后才显示
  检测到的当前版本和软件源最新版本，并询问是否安装；失败、无法识别或取消时不生成安装命令。自动环境复检完成后
  在日志和状态栏输出安装前／软件源最新／更新后版本及实际结果。
- 改进：统一扫描的完整／快速按钮内部间距保持不变，在扫描模式与生成方式之间增加独立
  10 px 纵向留白，明确两级选择关系且保持各行 Y 轴居中。
- 改进：档案数据解析使用独立的「解析数据库」操作行，并与硬盘页「检测硬盘」对齐；
  「内容预设／内容模块」最终统一为「导出范围／数据模块」，范围改用按钮，默认全部内容，
  HTML/XLSX/CSV/JSONL 默认全选且范围切换不覆盖手动格式选择。
- 改进：六个功能说明和字段帮助改为直接用途短句，悬停提示按实际字体像素宽度自然
  换行；运行进度与运行日志统一使用暖米色面板配色。全部内容的数据模块项采用紧凑自适应列数，
  标准字号下的默认 1080p 页面不再产生空白滚动范围。
- 改进：「恢复默认」不再弹出确认；管理员模式由滑动开关改为固定尺寸按钮并移入
  「硬盘信息登记」页，提权后显示绿色并禁止重复触发，任务运行中仍不可操作。硬盘简化报告
  默认生成，底层 `--summary-txt` 和 ZIP 结构不变。
- 测试：此前检查点的仓库自动化 633/633 通过，failure 0、error 0；真实 Tk 覆盖固定按钮 UI、
  多字体、3 档字号、1.0/1.25/1.5 scaling 和支持范围内的多种窗口尺寸。默认 1080p
  六个正式页面无可见滚动，真实溢出时可到达最后一项；正式页面交叉矩阵共 324 组。上述
  后续顶部入口、字段命名和根目录对应小修按要求只执行相关定向测试，结果为 14/14 通过；
  本次逐工具元数据三态、默认校验、间距、恢复默认和管理员按钮续改又完成 68 个不重复的
  定向用例，全部通过。最新双按钮循环、环境检测、解析格式、管理员位置和 1080p 小修另执行
  10 项定向测试，10/10 通过。最终文案、UI 与数据消费者定向专项完成 342/342；授权目录内
  44 个 v1.4.1/schema 3 完整扫描库完成只读清点，2 个代表库完成四格式真实导出，1 个最大库
  完成 15/15 个数据模块识别与规划；发布前仍需再跑完整回归。
- 限制：本轮未把真实异常媒体、全部外部工具版本、真实物理硬盘和长时间海量扫描纳入
  稳定发布验收，因此自动化通过不能等同于稳定版结论。
- 兼容：不升级 schema，不修改 Diff 或 Reader 投影；冻结 schema 3
  `full-scan`、`quick-scan` 参数保持不变。所有数据库消费者继续只读支持 v1.4.1 封存库。

## 2026-08-07 — DAISY v1.6.0（可靠性、兼容与报告重构）

- 改进：GUI 数据域收敛为「扫描、对比、核验、数据库解析」。旧 `full-scan／quick-scan／
  check-hash／check-format／export-report` 参数和投影继续作为兼容入口保留。
- 新增：统一 `scan` 使用 schema 4、独立续传契约、run session、entry attempt、CAS 状态、
  lease／心跳和 no-clobber 发布。支持同会话暂停／继续、保存进度并退出、下次确认续传，
  以及与之语义不同的停止任务。
- 新增：哈希读取使用隔离 worker。无进展 timeout 默认 90 秒，每 9 GiB 增加 90 秒；提供
  继续等待、跳过并记录、停止并保留续传，无人选择时默认继续等待。数值进度最多 500 ms、
  可选当前文件最多 100 ms 发送一次。
- 新增：Full 可附加默认关闭的格式校验。RAW 深度校验默认关闭且从属于格式校验，通过
  统一能力层检查 rawpy，并在独立子进程实际执行 LibRaw 解码；不支持类型只统计，解码
  失败、截断和 timeout 进入伴随报告，不改变 SQLite schema。
- 新增：统一 `verify` 组合 stat、内容哈希、格式与 RAW 深检。哈希和格式结论、抽样和报告
  保持独立；unsupported 不作为文件问题。
- 新增：DBS-41 重构为数据库解析。Reader 自动识别快照／Diff 和模块能力，提供三种内容
  预设、快照 15 个模块、Diff 6 个模块，以及自包含 HTML、中文 XLSX、CSV、JSONL 和
  manifest；输入只读、流式投影、staging 和 no-clobber 发布。
- 新增：统一 Reader 只读支持 schema 3／4。DBS-21 跨版本 Diff 覆盖 3→3、3→4、4→3、
  4→4；旧库缺少新能力时显示 `NULL／不可用`，不迁移、不回写、不伪造 0。
- 改进：`_Issues.md` 固定分为枚举、哈希、Exif／元数据、格式、RAW、读取性能候选和
  运行／证据板块。普通 warning 与 `CopyN` 动态字段折叠；不认识格式只统计；工具故障
  只输出聚合事件，不扩散为逐文件问题。
- 修复：ExifTool 的 EOF、退出、write／flush `OSError 22` 会立即废弃旧会话，回收、重建
  并有限重试。ffprobe、7-Zip、rawpy、哈希 worker、PowerShell 哈希和 smartctl 使用统一
  工具故障分类、受控输出、原生进程退出识别、精确回收与默认 3 次连续失败熔断；schema 4
  熔断转为 `failed_recoverable`，禁止误封存。
- 改进：保留 v1.5.1 的 1080p、字体／字号／比例、无空白滚动、小窗往返、独立日志、统一
  六字标题和按钮设计。二态选项可在顶部切换黄色／绿色按钮或下拉菜单；多值选项不变。
- 新增：顶部「设置」提供默认关闭、持久化的任务完成提示音。普通任务正常完成或「完成但
  需要检查」时异步播放一次；失败、暂停、保存退出、停止、安装和硬盘检测准备阶段不播放。

  DDL、元数据 profile 7 和 `min_reader_version=1.4.1` 保留。v1.4.1 未完成 partial 不由
  v1.6.0 直接接管，旧程序也不承诺读取新的 schema 4。

  工具故障注入和最终发布回归见
  [v1.6.0 测试记录](Spec_DAISY_V1_6_0_Test_Record.md)。
