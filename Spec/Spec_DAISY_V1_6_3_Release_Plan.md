# DAISY v1.6.3 UI 整理计划

- 目标版本：v1.6.3
- 基线：v1.6.2 发布提交 `cfa3fa3e522916fc18c84d083d01b8b10ae67341`
- 当前状态：本地 `Codex` 分支开发检查点；未推送、未建立 tag
- 数据兼容基线：v1.4.1/schema 3 FULL 封存快照

## 一、目标

v1.6.3 只整理可见 UI 和交互一致性，不扩展数据库或扫描能力：

1. 顶部入口使用「扫描建库、快照对比、数据核验、数据解析、硬盘登记、环境检测」六个四字短名；完整功能名继续用于页面标题、进度、日志和报告。
2. 扫描建库与数据核验的「档案根目录」使用同一个可编辑目录列表组件。
3. 「解析数据库」与「检测硬盘」使用同一浅绿色主操作样式。
4. 硬盘选择的所有设备槽位使用同一边框、内边距、宽度和高度规则。
5. 顶部菜单按「文件／功能／视图／设置／高级／帮助」排列；功能按档案、设备、环境分组，
   工具路径归入设置，扫描／核验／对比运行选项归入高级。菜单项使用短名称，工具路径不
   展示完整路径；菜单字号与正文同步。顶部六个功能按钮与环境页六个检测／安装列共享
   横向起点、按钮宽度和间距。
6. 所有任务表单的离散选项使用按钮，不创建下拉框。续传重试范围使用三个互斥按钮；
   数据库解析的摘要／全部／自定义预设原位更新模块池，不重建整张表单。
7. 文件选择小按钮统一为「添加／选择／浏览」；环境状态与安装按钮使用固定紧凑宽度，
   保持上下对齐但不横向填满整行。
8. 「重置软件」统一放在顶部功能栏并移除设置菜单的重复恢复入口；底部三个常驻按钮从右
   向左固定为开始／停止、暂停／继续、打开结果目录，同一个开始按钮在运行时原位变为停止；
   安全暂停后才在左侧显示保存并退出。各按钮使用同一尺寸规则。
9. 任务结束默认不弹出结果目录询问；有效结果让琥珀色目录按钮以绿色闪烁两次。设置菜单提供
   默认关闭、持久化的「结果目录提示」。
10. 新安装、非法配置回退和「重置软件」使用 `1600×900` 默认窗口；用户明确保存的其他
    窗口尺寸继续保留，设置菜单仍提供 `1920×1080`、`1600×900` 和 `1366×768`。

## 二、交互与数据约束

- 目录列表仍逐行保存路径或「根目录名=路径」；`--root` 参数的生成、绝对路径转换和校验规则不变。
- 核验页不能因为控件统一而丢失多根快照的手工根目录名配对能力。
- 硬盘槽位可因在线、可登记或脱机而改变状态文字、颜色和可点击性，但不能改变卡片几何结构。
- 顶部短名只用于入口按钮和「功能」菜单；设置页、进度、恢复提示和报告不得使用含义不清的缩写。
- 标准 Windows 菜单继续存在；「无下拉框」专指任务设置表单，不把菜单栏误改成自绘按钮。
- 按钮提示不得抢焦点或自动打开目录；结果目录不存在、任务失败、停止、依赖安装或硬盘检测
  准备步骤不得提示。
- 用户配置格式升级为版本 3；旧配置缺少结果目录提示键时必须安全回退为关闭。
- v1.6.3 不新增、删除或修改任何 DBS 表、列、索引、触发器、STG Manifest 字段或 CLI 参数。

## 三、兼容边界

- `SCHEMA_VERSION=3`、统一扫描 `SCHEMA_VERSION=4`、STG `ARCHIVE_SCHEMA_VERSION=3` 保持不变。
- v1.4.1/schema 3 FULL 继续由统一 Reader 只读打开；不迁移、不回写旧库。
- Diff、扫描建库、哈希、元数据、格式核验和数据库解析的数据逻辑不得因本轮 UI 修改而变化。
- 应用版本更新为 1.6.3 只标识程序版本，不代表数据库契约升级。

## 四、测试与审查计划

1. 运行 Python 语法检查和 `git diff --check`。
2. 定向验证两处目录控件为同一类、同一按钮样式和宽度，并验证「根目录名=路径」原样收集。
3. 定向验证数据库解析与硬盘检测按钮使用同一浅绿色样式、尺寸和左对齐位置。
4. 使用 3 个长短文字、可用性不同的硬盘夹具，验证槽位等宽、等高、同背景和同边框。
5. 验证顶部 6 个入口保持单排、等宽、等高、左对齐，工作流顺序与四字短名固定；页面完整标题不变。
6. 遍历所有非顶部 `choice`／非布尔 `choice_flag`／`disk_choice` 字段，确认实际控件均为
   `ChoiceButtonGroup`、重复点击当前值保持控件和文字、切换后内部 CLI 值正确，且全表单无
   `ttk.Combobox` 实例。
7. 对数据库解析预设至少执行「摘要 → 全部 → 自定义 → 摘要」循环，逐次核对表单、预设控件、
   模块池和输出格式控件对象身份不变，格式选择不被覆盖。
8. 验证菜单树顺序、短名称、菜单字体随字号变化；验证重置软件父级、任务按钮顺序、尺寸、
   间距和运行期禁用状态。
9. 验证结果目录提示默认关闭、配置往返和默认值恢复；成功／需检查任务突出按钮，默认不调用
   询问，启用后才调用；停止、失败、依赖安装和硬盘检测准备步骤不触发。
10. 运行 1100 px 最小普通宽度、默认 `1600×900`、1080p、候选字体、三档字号与多档
    Tk scaling 的真实
    Tk 几何矩阵，检查遮挡、裁切、非真实滚动、按钮换行和点击状态。
11. 验证目录参数、v1.4.1 Reader／Diff／核验／解析兼容测试不回退。
12. 正式推送或建立 tag 前，另行运行完整自动化套件并补写最终测试证据。
